# Level 2 Task 3 – To-Do Web App

## Project Overview

A professional and responsive To-Do Web App developed as part of the OIBSIP Web Development & Designing Internship.

The application allows users to create, manage, edit, complete, and delete daily tasks.

## Features

- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Edit existing tasks
- Delete tasks
- Display pending, completed, and total task counts
- Store tasks using browser localStorage
- Tasks remain available after refreshing the page
- Responsive design for different screen sizes
- Empty-state message when there are no tasks

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
