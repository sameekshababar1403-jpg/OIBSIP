# 🧮 Professional Calculator

A responsive and user-friendly calculator web application developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 2, Task 1**.

The project provides essential arithmetic operations through a clean interface and supports both mouse/touch interaction and keyboard input.

---

## 📌 Project Overview

This calculator is designed as a modern web application with a focus on:

- Clean and organized code
- Responsive user interface
- Simple and intuitive interaction
- Reliable calculation handling
- Accessibility-friendly controls
- Proper error handling

The project was developed using standard front-end web technologies without relying on external frameworks.

---

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number calculations
- Clear calculator function
- Backspace/delete functionality
- Sequential calculations
- Operator chaining
- Division-by-zero handling
- Protection against multiple decimal points
- Keyboard support
- Responsive design for different screen sizes
- Accessible button labels and focus states
- Input length protection
- Floating-point result formatting

---

## 🛠️ Technologies Used

- **HTML5** – Structure and semantic markup
- **CSS3** – Styling, layout, responsiveness and visual design
- **JavaScript (ES6+)** – Calculator logic and user interaction
