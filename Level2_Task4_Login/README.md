# Level 2 Task 4 – Login Authentication System

## Project Overview

A secure and responsive Login Authentication System developed as part of the OIBSIP Web Development & Designing Internship.

The application allows users to create an account, securely validate their password, log in, maintain a session, and log out.

## Features

- User registration
- Email and password validation
- Password strength validation
- Password confirmation
- Duplicate account prevention
- Secure password hashing using SHA-256
- User login authentication
- Incorrect credential handling
- Session persistence using sessionStorage
- Protected dashboard after successful login
- Logout functionality
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API
- localStorage
- sessionStorage
